# Security policy

hams types into other apps, reads a global key, and records the microphone, so security
reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue.** Use GitHub's private reporting instead: go to the
repository's **Security** tab and choose **Report a vulnerability**. You will get a reply within
a week.

Useful things to include: the OS and hams version, what an attacker could do, and steps to
reproduce.

## Supported versions

Only the latest release gets security fixes.
